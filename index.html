Tokens Tester

Check design-token files for DTCG compliance, contrast and color-vision accessibility.

Runs in your browser. Your tokens never leave it.

Files are read and processed on this page only. Their names, values and structure are never uploaded, stored or sent anywhere.

The only network request this page makes is to a URL you type in, and only when you click Load.

Check it yourself: open your browser's developer tools, go to the Network tab, and load a file. Nothing is sent. You can also turn off Wi-Fi after the page loads; everything keeps working.

For full isolation, clone the repository and run the strict build (npm run build:strict), which works offline from a local file.
